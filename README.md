# CINIS LAURI / Пепел лавра

Оригинальная мобильная 2D игра о гражданских войнах Рима, 58 до н. э. — 14 н. э.
**Часть 1 из 3: визуальная основа и AssetGallery.** Godot 4.x, GDScript, Android,
ландшафт, 320×180, nearest и целочисленное увеличение.

36 наборов: 15 персонажей с девятью ключевыми позами и портретом, 12 локаций
с тремя слоями параллакса, 4 тайлсета/набора объектов и 5 наборов UI.
RPG, пошаговая тактика и платформер относятся к следующим частям.
Большие исходники созданы встроенным генератором изображений; игровые PNG
воспроизводимо обработаны Pillow и используют общую палитру 24 цветов.

## Запуск

Откройте `project.godot` в **Godot 4.6.3** (проверенная версия) и нажмите F5.
Или из корня проекта:

```sh
godot --editor --path .
godot --path .
```

В галерее четыре категории. Стрелки и свайп листают наборы, «Поза» переключает
девять ключей персонажа, «Движение» включает параллакс. «Чистый вид 1:1» скрывает
панели для полного просмотра в игровом масштабе. Касание/клик возвращает панели.
С клавиатуры: ←/→, Tab, пробел, F или Esc. На экране 1280×720 пиксель увеличивается
ровно в 4 раза; на несовпадающих пропорциях остаются поля, растяжения нет.

## Пересборка арта и проверки

```sh
python -m pip install -r tools/requirements.txt
python tools/pixelize.py
python tools/build_resources.py
python tools/contact_sheet.py
godot --headless --editor --path . --import --quit
python tools/validate_assets.py
godot --headless --path . --script tools/verify_gallery.gd
```

Один набор: `python tools/pixelize.py titus_pullo`. Для произвольного файла:
`--input`, `--output`, `--crop`, `--size`, `--remove-background`.
Удаляется заранее заданный пурпурный фон; белая одежда и пергамент сохраняются.
Прозрачность бинарная. Позы выделяются по связным компонентам, поэтому меч
не обрезается по формальной колонке исходника. Во всех позах персонажа один масштаб.

## Структура

- `assets/characters`: PNG 144×192 (3×3, кадр 48×64), портреты 96×96, SpriteFrames `.tres`.
- `assets/locations`: композиции 320×180 и отдельные `_far`, `_mid`, `_near`.
- `assets/tiles`: атласы 128×128, тайлы 16×16, готовые TileSet `.tres`.
- `assets/ui`: диалог, кнопки, стрелки, 7 иконок, карта, инвентарь, логотип.
- `art_src`: большие исходные PNG; исключены из импорта/экспорта через `.gdignore`.
- `tools/manifest.json`: реестр 36 наборов, источников, размеров и статусов.
- `docs`: художественная библия, статус, источники, контактные листы, проверки.
- `scenes/AssetGallery.tscn`, `scripts/asset_gallery.gd`: главная сцена просмотра.
- `story`: зарезервировано для следующей части.

Порядок кадров: front, side, back, idle, walk, run, attack, block, hurt.
У гражданских персонажей attack/block — жесты действия и защиты.
Один нарисованный ключ на состояние. Галерея добавляет дыхание, смещение и отклонение
кодом; это ещё не полноценные циклы ходьбы и боя. У тайлсетов пока нет коллизий,
terrain-переходов и навигации — они появятся вместе с игровыми уровнями.

## Android

Есть пресет `Android` для ARM64 без сетевых разрешений. После установки Android
export templates той же версии Godot, JDK и Android SDK настройте их пути в редакторе
и используйте Project → Export → Android. Секреты подписи не включены.
APK и проверка на физическом телефоне не выполнялись в этой части.
