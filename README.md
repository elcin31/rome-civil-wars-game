# CINIS LAURI / Пепел лавра

Оригинальная 2D пиксельная игра о гражданских войнах Рима, 58 до н. э. — 14 н. э.
Godot **4.6.3**, GDScript, Android **7.0+ / ARM64**, ландшафт, без мультиплеера
и сетевых разрешений. Играбельная debug-версия **0.3.0**.

[Сборки и ZIP с APK](https://github.com/elcin31/rome-civil-wars-game/releases)
· [Текущая готовность](docs/STATUS.md) · [Известные ограничения](docs/KNOWN_ISSUES.md).

Восемь глав, 76 сцен, **34 355 слов**, 55 узлов выбора, 114 вариантов ответов,
10 крупных развилок, 11 побочных сцен и четыре концовки. После Рубикона
есть военная и гражданская линии; позднее — четыре политические позиции.
Расчётное чтение одного обычного пути: **120,6–135,8 минуты**, без времени боёв.
Альтернативные линии и концовки в это время не складываются.

Сюжетные игровые точки теперь исполняются: **10 тактических боёв,
10 платформерных эпизодов и 9 РПГ-хабов** во всём графе обеих линий.
Победы подтверждает игровая логика. Кнопка прежней заглушки удалена.

## Установка

Скачайте ZIP из Releases, распакуйте и откройте `cinis-lauri.apk` на Android.
Разрешите установку неизвестных приложений для используемого браузера или
файлового менеджера, затем нажмите «Установить». Инструкция есть внутри ZIP.
Это ARM64 APK с пакетом `org.cinislauri.game`, версией 0.3.0, minSdk 24,
targetSdk 36. Подпись отладочная; между CI-сборками она может меняться.
Удаление приложения удаляет его сохранения.

## Как играть

- Диалоги: касание/«Дальше» сначала раскрывает текст, затем листает страницы.
  Ответы показывают условия доступности. Пробел и Enter работают на ПК.
- Тактика: выберите отряд, затем клетку или цель. У каждого два очка действий;
  легион и конница бьют вблизи, лучники — с трёх клеток. Укрытия уменьшают
  урон, грязь замедляет, потери снижают мораль. «Конец хода» передаёт ход ИИ.
  В заданиях сопровождения охраняйте носильщиков/лодку в нижнем ряду.
- Платформер: джойстик слева, прыжок, удар и щит справа. Джойстик вниз + щит —
  уклонение. Соберите три метки и дойдите до выхода. Падение возвращает
  к частой контрольной точке; собранные предметы сохраняются.
- Хаб: подойдите к писцу → запасам → получателю → дороге и нажимайте «Дело».
  Торговец продаёт общие гладиус, щит и припасы; там же изучаются навыки.
  Репутация граждан и дипломатия дают скидку. «Герой» переключает Пулона/Ворена
  в безопасном хабе. Погибший напарник недоступен.
- Напарник следует за героем. Доверие открывает щитовое прикрытие и помощь
  при прыжке; оно также влияет на исходы истории.
- Пауза: кнопка вверху, Escape или системный «Назад». Здесь три ручных слота,
  настройки, журнал и использование припасов для лечения раненого героя.
  Автосохранение работает после решений, между сценами и внутри эпизодов.
  Повреждённый основной файл можно восстановить из последней валидной копии.
- Карта кампании показывает прогресс и возвращает к текущему событию,
  сохраняя прежние решения. Новая игра требует подтверждения перезаписи.

На ПК: A/D или ←/→ — движение, W/S или ↑/↓ — вертикаль джойстика в хабе,
Space — прыжок, J — удар, K — щит, Shift — уклонение, E — взаимодействие,
Enter — конец тактического хода. Два пальца на телефоне обрабатываются независимо.
В настройках меняются звук, скорость текста, размер и сдвиг игровых кнопок.

## Состояние проверки

19 GUT-тестов проверяют 131 условие; отдельный сюжетный раннер проверяет
24 маршрута. Бот действительно играет все 29 эпизодов, покрывает все
114 вариантов ответов и четыре концовки, проверяет загрузку внутри эпизода.
Это покрытие вариантов решений, а не всех их экспоненциальных комбинаций.

CI выполняет валидаторы, gdlint/gdformat, GUT, сюжетный раннер, игрового бота,
сборку и проверку подписи/метаданных APK. Отдельная задача запускает x86_64
экспорт того же кода на Android API 35: касания → первый хаб → поручение →
закрытие процесса → продолжение. Её результат смотрите в конкретном CI run.
Пользовательский APK остаётся ARM64.

## Запуск из исходников

Откройте `project.godot` в Godot **4.6.3** и нажмите F5:

```sh
godot --editor --path .
godot --path .
```

Проверки, совпадающие с CI:

```sh
python -m pip install -r tools/requirements.txt
godot --headless --editor --path . --import --quit
python tools/validate_assets.py
python tools/validate_story.py
python tools/validate_gameplay.py
gdformat --check scripts tools/*.gd tests
gdlint scripts tools/*.gd tests
godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit
godot --headless --path . --script tools/verify_gallery.gd
godot --headless --path . --script tools/verify_story.gd
godot --headless --path . --script tools/walk_game.gd
```

Для проверки одной главы: `godot --headless --path . --script tools/walk_game.gd -- --chapter=3`.
Линтеры проверяют код проекта; сторонний GUT сохраняет собственное оформление.

Пересборка арта: `tools/pixelize.py`, `tools/pixelize_story.py`,
`tools/pixelize_final.py`. Пересборка звука: `python tools/build_audio.py`
(нужен FFmpeg). Все процессы используют уже сохранённые источники.

## Структура и Android CI

- `story/chapters/ch01.json` … `ch08.json`: русский текст, выборы, сюжетные узлы.
- `story/beats.json`: 29 активных заданий; `gameplay_catalog.json` — их реестр.
- `story/chapter_index.json`: короткий индекс для загрузки глав по необходимости.
- `scripts/story_runtime.gd`: флаги, граф, история, сохранения и миграции.
- `scripts/gameplay/*_model.gd`: независимая логика трёх слоёв;
  `encounter_view.gd`: мобильный интерфейс; `progression.gd`: общие навыки/вещи.
- `scripts/game_services.gd`: настройки и ограниченный пул аудиоголосов.
- `tools/walk_game.gd`: прохождения реальными действиями; `tests/`: GUT.
- `docs/ART_BIBLE.md`, `HISTORY_NOTES.md`, `KNOWN_ISSUES.md`: стиль, источники, ограничения.

`.github/workflows/build-apk.yml` запускается при push в main и вручную.
Зафиксированы Godot 4.6.3, Java 17.0.13+11, Android SDK/build-tools 36/36.0.0.
Проверяются пакет, версия, min/target SDK, единственная ABI ARM64,
отсутствие INTERNET, подпись и предел 150 МиБ. ZIP содержит APK,
README_INSTALL.txt, метаданные и SHA-256 с исходным Git commit.
Большие художественные источники, документация, GUT и тестовые маршруты
исключены из APK.
