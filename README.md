# CINIS LAURI / Пепел лавра

Оригинальная офлайн 2D пиксельная история о Риме, 58 до н. э. — 14 н. э.
Godot **4.6.3**, GDScript, Android **7.0+ / ARM64**, ландшафт.
Финальная версия по [заданию PDF](docs/FINAL_REQUIREMENTS.md): **0.5.0**.

[APK и ZIP](https://github.com/elcin31/rome-civil-wars-game/releases/tag/v0.5.0)
· [Готовность](docs/STATUS.md) · [Проверки](docs/completion_validation.json)
· [Ограничения](docs/KNOWN_ISSUES.md).

## Игра

Восемь глав, 95 сцен, 66 сюжетных узлов выбора / 136 ответов, две основные
линии после Рубикона, политические позиции и четыре концовки.
**48 455 слов** сюжетного текста: 46 184 в главах и 2271 в катсценах.
Восемь интерлюдий содержат по 700–1000 слов; каждый эпилог — более 1500.
Шесть вымышленных второстепенных персонажей имеют личные линии.

Обычный полный маршрут с побочными сценами содержит около 36–38 тысяч слов.
Это **5,0–5,2 часа при 120 словах/мин** или **3,0–3,1 часа при 200 словах/мин**.
Темп чтения, выборы и вставки меняют фактическое время. Альтернативные
концовки и статьи Хроники не добавлены к длине одного прохождения.

Все прежние бои отключены в сюжетном графе. Вместо них работают **13 катсцен
с 78 новыми кадрами**, **7 коротких мягких вставок** и **20 мирных поручений**.
Камера, переходы, пыль/угли/дождь, звук, решения и три исхода задаются JSON.
Потеря продолжает сюжет. Зерно, выбор и проверка сохраняются; повтор не
перебрасывает исход и не выдаёт награду дважды. На исход влияют навыки,
снаряжение, подготовка, связь и прежние поступки. Один припас подготовки
расходуется в катсцене и даёт +1 к расчёту.

## Новые системы

- **Хроника:** 60 записей по 80–150 слов с источниками, поиск и четыре фильтра.
- **Галерея:** 179 картин и кадров, открытие по прогрессу, силуэты, счётчик,
  полный экран, масштаб и перемещение изображения.
- **Свиток судеб:** решения, их последствия, связь, репутация и итоги катсцен.
- **Ранее в игре:** 3–5 пунктов из флагов при продолжении и смене главы.
- **Карта:** пергаментное Средиземноморье, анимированный путь, годы,
  эпиграфы, иллюстрированные карточки и доступность глав.
- **Звук:** шесть оригинальных музыкальных настроений, четыре окружения,
  десять эффектов Ogg; весь звук менее 1 МБ. Раздельные громкости и
  приглушение музыки при чтении.
- **Комфорт:** три размера текста, скорость печати, пропуск прочитанного,
  автопродолжение, вибрация, 30 FPS, левая рука, подсказки и пропуск вставок.

Добавлено **118 новых оригинальных композиций поверх прежних 292 PNG**:
78 кадров, 20 иллюстраций Хроники и 20 нового сюжета/систем. Производные
кропы и миниатюры не засчитаны отдельно. Исходники, референсы и промпты:
[art_src/waves](art_src/waves); игровой формат — индексированный PNG
480×270, единая палитра 48 цветов, nearest и очистка одиночных пикселей.

## Управление

Диалог: «Дальше» сначала раскрывает страницу, затем листает. «Показать текст»
раскрывает её сразу; ответы с условиями становятся доступны по поступкам.

Поручение: джойстик → писец → отмеченный предмет → получатель → дорога.
Одна контекстная кнопка появляется у героя. Цель задания имеет приоритет
над соседним торговцем. «Что дальше?» и журнал объясняют текущий этап.
После 20 секунд бездействия включается отключаемая подсказка.

Катсцена: можно ждать перехода, нажать «Следующий кадр» или пропустить
изображения до решения. Решение не пропускается автоматически. Мягкая
проверка необязательна; «Принять последствия» продолжает историю при любом
исходе. «Повтор» позволяет ещё раз посмотреть сцену до принятия результата.

Короткий путь: «Влево», «Вправо», «Тихий шаг»; патруль замедляет, но не
убивает. Кости в лагере предлагают ставку или спокойную игру. При Акции
нужны три нажатия в широком окне; переговоры предлагают проверяемый довод
или давление. Любую вставку можно пропустить с нейтральным влиянием.

Пауза — верхняя кнопка, Escape на ПК или системная кнопка «Назад».
Есть автосохранение, три ручных слота, резервная копия и миграция прежних
сохранений. Снимок прежнего боя заменяется новой катсценой/мирным эпизодом;
пройденные главы и решения сохраняются.

## Установка

Скачайте ZIP, распакуйте и откройте `cinis-lauri.apk`. Разрешите установку
для браузера/файлового менеджера и нажмите «Установить». Инструкция внутри.
Пакет `org.cinislauri.game`, версия **0.5.0 / code 7**, minSdk 24, targetSdk 36,
только arm64-v8a. Разрешение VIBRATE нужно для отключаемого отклика;
разрешения INTERNET нет. Подпись отладочная: между CI-сборками может
потребоваться удаление прежней версии. Удаление удаляет локальные сохранения.

## Проверка и разработка

```sh
python -m pip install -r tools/requirements.txt
godot --headless --editor --path . --import --quit
python tools/validate_assets.py
python tools/validate_story.py
python tools/validate_portraits.py
python tools/validate_gameplay.py
python tools/validate_completion.py
gdformat --check scripts tools/*.gd tests
gdlint scripts tools/*.gd tests
godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit
godot --headless --path . --script tools/verify_story.gd
godot --headless --path . --script tools/walk_game.gd
godot --headless --path . --script tools/walk_alternatives.gd
python tools/run_display.py python tools/ui_matrix.py
python tools/run_display.py python tools/ui_matrix.py --quick --size=1280x720 --density=2.625
```

CI проверяет семь разрешений от 800×480 до 2560×1080, безопасные области,
текст, пересечения и реальные ScreenTouch по кнопкам. Боты проходят 24
маршрута и ещё 16 кампаний с другими решениями/зёрнами. Каждый хаб проверен
во всех 120 начальных порядках посещения объектов.

Android APK собирается через `.github/workflows/build-apk.yml` с закреплёнными
Java 17, Godot 4.6.3 и SDK 36. Эмулятор API 35 проверяет холодный запуск,
поручение, рестарт и катсцену касаниями, не изменяя сохранение.
Стабильная публикация допускается только при успешном полном CI.

Golos Text и PT Serif сохраняют ранее выбранную читаемую кириллицу;
Tiny5 остаётся в архиве. Лицензии и авторство: [CREDITS](docs/CREDITS.md).
Исторические границы вымысла: [HISTORY_NOTES](docs/HISTORY_NOTES.md).
Физические проверки звонка, аудиофокуса, вибрации и производительности
остаются в [ручном чек-листе](docs/QA_CHECKLIST.md).
