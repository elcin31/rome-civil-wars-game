# Проверка версии 0.3.0

17 октября 2026. Фактические отчёты: story_validation.json,
gameplay_validation.json, desktop_performance.json, GitHub Actions.

## Логика и сюжет

19 тестов GUT 9.5.0 / 131 проверка. Независимый Python-интерпретатор сверяет
условный сюжет с Godot на 24 сценариях. Игровой бот использует те же модели
движения/боя/хаба, что экранное управление: никаких присвоений won=true.
Он покрывает все 29 точек, 114 вариантов ответов и четыре концовки.
Покрытие вариантов не означает перебор всех комбинаций.

Общий результат: 192 боя, 200 платформерных исполнений, 192 хаба, 166 898
шагов. Бот ходит к торговцу, использует реальную прогрессию и восстанавливает
снимок эпизода через настоящий файл сохранения. GUT отдельно сохраняет
прыжок после получения предмета и тактику после первого хода.

Новый формат аддитивен к schema_version=2: старые флаги восстанавливаются
из решений, XP — из реально отмеченных завершённых игровых точек; эффекты
не повторяются. Невалидные записи истории и вложенные состояния отвергаются,
повреждённый файл не вытесняет последнюю валидную резервную копию.

## Экран и производительность

Кадры сделаны настоящим рендерером Godot, не макетами. Исправлено зеркалирование
вражеских спрайтов; контролируемая фигура отмечена «Вы». Статичная тактическая
доска перерисовывается при действии, а не каждый физический кадр.

Xorg dummy, Mesa llvmpipe, программный OpenGL, ограничение 60 FPS:
после 180 кадров прогрева взято по 120 кадров на слой. Минимум/максимум
во всех трёх слоях — 60/60 FPS; максимум CPU-кадра 15,58 мс, статическая память
Godot не выше 31,57 МиБ. После 20 пауз/возвратов число узлов 15 → 15.
Окна 1280×720 и 1680×720 сохраняют композицию 320×180 с полями.

Это измерения ПК с виртуальным дисплеем и Dummy-аудио. Они не доказывают
60 FPS/≤600 МБ на телефоне. Полная память процесса, GPU и драйверы Android,
аудиофокус, системные прерывания и реальный холодный запуск — отдельная QA.

## Android

CI фиксирует Godot 4.6.3, Java 17, SDK/build-tools 36/36.0.0. Финальный файл
имеет ABI arm64-v8a, minSdk 24, targetSdk 36, пакет org.cinislauri.game,
версию 0.3.0/code 3; проверяются подпись и предел 150 МиБ.

Эмуляторная задача строит отдельный x86_64 APK из тех же игровых файлов,
устанавливает его на API 35, читает начало касаниями, идёт джойстиком к писцу,
принимает поручение, уходит в фон, закрывает процесс и продолжает с диска.
Кадры, logcat и JSON-отчёт публикуются как android-smoke-evidence.
Точное состояние последнего запуска смотрите в STATUS.md и Actions.
