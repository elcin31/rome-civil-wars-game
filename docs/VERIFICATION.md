# Проверка части I

Дата: 2026-10-16. Godot **4.6.3.stable.official.7d41c59c4**, Python 3,
Pillow 12.3.0, Linux. Графическая проверка: X11 dummy display, OpenGL 4.5,
Mesa llvmpipe. Все команды запускались из корня проекта.

## Автоматические проверки

```sh
godot --headless --editor --path . --import --quit
python tools/validate_assets.py
godot --headless --path . --script tools/verify_gallery.gd
```

Итог после последнего изменения масштаба персонажей:

```text
36 logical assets; 89 PNGs; 24 palette colors; 0 errors
GALLERY PASS: 36 assets, 135 character keys, 36 parallax layers, 256 tile regions
```

Импорт завершился с кодом 0, ошибок парсинга GDScript и ресурсов нет.
Отчёт по каждому PNG: `validation.json`; геометрия выделенных исходных поз:
`pixelize_report.json`. Проверяются источники, размеры, видимые цвета, бинарная alpha,
прозрачность спрайтов/портретов/слоёв, отсутствие пустых и обрезанных поз,
отключённые mipmaps, наличие SpriteFrames и TileSet.

Проверка сцены загружает все 36 записей, все 15 SpriteFrames, все 4 TileSet,
обходит девять поз каждого персонажа и циклическое перелистывание в обе стороны.
Также выполняются события свайпа и клавиатуры, сигналы кнопок категорий и действия,
скрытие/возврат интерфейса и проверка размеров кнопок внутри viewport.

## Проверка отрисовки

```sh
DISPLAY=:99 godot --audio-driver Dummy --path . --script tools/capture_gallery.gd
```

Нужен работающий X11-дисплей; `:99` относится к использованной рабочей среде.
Снимки получены чтением viewport настоящей сцены после отрисовки кадров:

- `gallery_hero.png`: Пулон, ключ 48×64, портрет 96×96.
- `gallery_alesia.png`: композиция трёх слоёв с двойной линией укреплений.
- `gallery_tiles.png`: городской атлас с прозрачностью на контрольной сетке.
- `gallery_map.png`: карта в масштабе 320×180.

Все четыре снимка имеют размер 320×180. Вручную просмотрены категорийные контактные
листы после окончательного квантования. Общий лист `contact_sheet.png` содержит
все **89** игровых PNG; `contact_overview.png` — обзор **36** наборов.
Общий объём игровых PNG — 1 932 268 байт; большие исходники хранятся отдельно.

## Границы проверки

Полноценный игровой цикл, боевые анимации, Android APK и физический телефон не
проверялись: в этой части создана визуальная основа. Android preset подготовлен;
для APK потребуются export templates и SDK. Ручная доводка стыков, анимационных
ключей и географии карты перечислена в ART_BIBLE. Все исходники сохранены.
