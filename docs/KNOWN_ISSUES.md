# Известные проблемы и ограничения 0.3.0

Обновлено 17 октября 2026. Играбельная debug-сборка, основная история закончена.

| ID | Статус | Проблема / предел проверки |
| --- | --- | --- |
| QA-01 | требует устройства | 60 FPS, холодный старт ≤5 с и полную память ≤600 МБ нужно измерить на среднем физическом Android. ПК: 60 FPS после прогрева, статическая память Godot ≤31,6 МиБ. |
| QA-02 | требует устройства | Реальный звонок, аудиофокус/Bluetooth, вырезы, фактические 48 dp, низкая память и убийство ОС — ручной чек-лист. |
| ART-02 | открыто | Девять ключевых поз вместо полноценных циклов. Нужны ручная чистка кластеров, возрастные спрайты, отдельные спрайты лучников/конницы (сейчас общий солдат + обозначение типа) и уточнение исторической архитектуры/декораций. |
| LOC-01 | открыто, необязательно по заданию | Английский перевод отсутствует; поля en подготовлены, меню не предлагает пустой язык. |
| SIGN-01 | ограничение debug | CI создаёт отладочную подпись заново; между сборками может потребоваться удаление прежней версии с потерей локальных сохранений. Для обновлений нужен постоянный ключ владельца. |
| GAME-01 | исправлено | Кнопочные заглушки заменены 29 настоящими заданиями: 10 тактических, 10 платформерных, 9 хабов. |
| SAVE-01 | исправлено | Три слота, атомарная запись, валидная резервная копия, миграция прежних флагов и XP за завершённые задания. |
| SAVE-02 | исправлено | После JSON-загрузки числа нормализуются: предметы не дублируются, тактические команды восстанавливаются. Проверено в середине прыжка/боя. |
| HERO-01 | исправлено | После гибели Ворена управление переходит к Пулону; погибший напарник не появляется в игровых слоях. |
| BUILD-01 | исправлено | Финальный run 39003213216 зелёный, включая Android smoke, кадры и восстановление. |
| BUILD-02 | обойдён | После двух ошибок конфигурации Gradle-путь оставлен. Используется готовый шаблон Godot 4.6.3, SDK 24/36; включён обязательный ETC2/ASTC import. |
| ART-01 | исправлено | 9 финальных композиций, иконки и пять переходных экранов подключены, общая палитра проверена. |
| BALANCE-01 | ручная доводка | Максимальная сложность рассчитана на предыдущий XP и лавку. Бот проходит все маршруты с обычной прогрессией; настройка удобства/сложности для живого игрока ещё желательна. |
| AUDIO-01 | обход среды проверки | Dummy-драйвер при выходе из графического захвата удерживал Ogg-ресурсы. После двух наблюдений воспроизведение в headless/Dummy отключено; в игре с настоящим аудиодрайвером оно включено. Проверка реального аудиофокуса остаётся QA-02. |
| SMOKE-01 | исправлено в тесте | Первый эмуляторный запуск обращался к прежнему имени Activity. Фактический launcher — GodotAppLauncher; тест теперь получает компонент через Android Package Manager. Подтверждено финальным Android-сценарием. |
| SMOKE-02 | исправлено в тесте | Просмотр кадров выявил стандартную системную подсказку immersive mode после холодного запуска. Подсказка подтверждена; после загрузки проверено реальное движение героя. |
| EMU-01 | обход | Два Android-кадра на swiftshader_indirect оказались пустыми: лог показал превышение GL_MAX_FRAGMENT_UNIFORM_VECTORS при линковке встроенных шейдеров Godot. Тестовый GPU заменён на swangle/ANGLE ES 3.1; финальные кадры видимы, ошибок шейдеров нет. |

Заглушек, завершающих бои одной кнопкой, в игровом интерфейсе нет.
Перечисленные художественные ограничения относятся к доводке существующих
ресурсов, а не к отсутствующим главам/механикам. Исходные ошибки CI сохранены
в истории запусков; подробности — STATUS.md и QA_CHECKLIST.md.
