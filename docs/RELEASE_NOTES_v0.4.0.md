# CINIS LAURI / Пепел лавра — 0.4.0

Мобильный интерфейс использует широкие экраны и safe area; диалоги больше
не перекрываются кнопками. Новый пиксельный шрифт с кириллицей и римские рамки.
Всем говорящим добавлены портреты с четырьмя эмоциями. Лагерь получил землю,
тени, маркер цели и контекстное действие; исправлены двойные касания.

58 новых художественных наборов, обновлённые персонажи, меню и фоновые сцены:
48 цветов, мир 640×360, персонажи 64×96, портреты 128×128.
Сюжет, 29 игровых эпизодов, сохранения и 114 вариантов ответов сохранены.

ZIP содержит ARM64 APK, README_INSTALL.txt, метаданные и SHA-256 исходного APK.
Android 7.0+, без сетевых разрешений. Debug-подпись CI: при несовпадении подписи
обновление поверх 0.3.0 может быть недоступно; удаление игры удаляет сохранения.
Проверки и сборка — GitHub Actions, семь разрешений и Android API 35 эмулятор.
Физический средний телефон, аудиофокус/звонки, полные циклы анимации и возрастные
спрайты требуют ручной проверки/доводки.
