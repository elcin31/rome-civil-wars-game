Между строками ROUTE PASS и итогом также выведены 16 SCENARIO PASS:
для каждой линии три другие стороны, предупреждение обеих групп без побочных

с последующей жертвой и жертва при низком доверии.

Python проходит граф и экспортирует решения. Godot начинает новое состояние,
совершает те же реальные выборы и завершает слоты. Сравниваются концовка,
bond, все флаги, репутации и последовательность условных текстов в журнале.
Готовое состояние перед последним экраном не подставляется. Восемь канонических
путей используют автосохранение; дополнительные сценарии не повторяют запись
на диск для каждой реплики. Это 24 свидетельства, не исчерпывающий перебор.

Проверены также:

- Недоступный ответ возвращает false и не меняет состояние, даже если вызвать
  метод выбора напрямую. Нерия требует доверия, совместный канат — помощи
  Аглае и нужного bond. Без этих условий доступны другие исходы.
- Предупреждения 43 года выбирают правильные эпилоги; после `friend_lost`
  Ворен не появляется как говорящий в поздних сценах.
- Вход в гражданскую главу 3 создаёт достижимое состояние через предыдущие главы.
- Запись, повторная загрузка без дублирования журнала и без повторных эффектов.
- Старое сохранение без двух новых флагов восстанавливает их из сделанных
  предупреждений; отсутствие исходного обязательного флага отклоняется.
- Выбор жертвы у Акция → автосохранённый слот → загрузка → верное последствие,
  с неизменным bond и уже применённым флагом.
- Разбиение **всех** текстов на страницы сохраняет слова и даёт не больше
  четырёх строк; раскрытие не переходит к новому узлу, пропуск меняет сцену.
- Повреждённый JSON отклоняется. Тестовые файлы изолированы от сохранения игрока.

После настройки bond положительный путь без побочных сцен заканчивается на
95/93; с побочными сценами достигает 100 в поздней истории. Ранние ответы
больше не заполняют шкалу в первых главах.

## Визуальная проверка

Девять кадров получены самим Godot через Xorg и OpenGL/llvmpipe:

- `story_menu.png`, `story_dialogue.png`, `story_choice.png` — чтение и управление.
- `story_beat.png`, `story_log.png`, `story_ending.png` — слот, журнал и конец.
- `story_factions.png` — четыре ответа в доступной области экрана.
- `story_epilogue.png` — два старых героя без молодых портретов поверх сцены.
- `story_loss.png` — условное изображение и текст после утраты.

Кадры создаёт `tools/capture_story.gd`: он готовит состояния для просмотра;
доказательство прохождения даёт отдельный `verify_story.gd`.
Проверены подписи кнопок, закрытое условие, поздние портреты, четыре строки
и иллюстрации. Старое изображение двоих удалено из дороги 30 года:
семидесятилетние герои показаны только в позднем эпилоге/его воспоминаниях.

```sh
DISPLAY=:99 godot --audio-driver Dummy --path . --script tools/capture_story.gd
```

Дисплей :99 — условие среды снимков, не требование игры. Драйвер предупреждает
о невозможности сменить VSync, кадры сохраняются. Импорт редактором проходит;
Android build-tools в этой среде отсутствуют.
