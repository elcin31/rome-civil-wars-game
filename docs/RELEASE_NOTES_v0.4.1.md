# CINIS LAURI / Пепел лавра — 0.4.1

Новая типографика для чтения на телефоне: Golos Text для диалогов и интерфейса,
полужирные подписи кнопок и имена, PT Serif для крупных заголовков.
Полная кириллица, сглаживание, более свободные интервалы и увеличенная область
диалога. На плотных экранах основной текст увеличивается до 16 sp,
число строк на странице подбирается по высоте. Длинным подсказкам лагеря выделено больше места.
Пиксельная графика мира сохранена.

Проверки: все сюжетные страницы, семь разрешений, плотность 420 dpi,
реальные касания и Android-эмулятор с восстановлением сохранения.
ARM64, Android 7.0+, без сетевых разрешений. ZIP содержит APK и инструкцию.
При смене debug-подписи может потребоваться переустановка; удаление приложения
удаляет локальные сохранения. Постоянный ключ владельца ещё не настроен.
