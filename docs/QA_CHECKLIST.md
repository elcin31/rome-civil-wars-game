# Проверка Android 0.3.0

17 октября 2026. Автоматические проверки не заменяют физический телефон.
APK: ARM64, Android 7.0/API 24+, ландшафт, без разрешения INTERNET.

| Сценарий | Автоматическая проверка | Физический Android |
| --- | --- | --- |
| Все главы, две линии, четыре концовки | 24 маршрута, все 114 вариантов ответов и 29 игровых точек | Перечитать текст и оценить темп |
| Пауза и возврат | Снимок эпизода, восстановление; 20 циклов без роста числа узлов | Свернуть на 1/10/30 минут |
| Сохранение посреди сцены | История, эффекты без повтора, загрузка во время прыжка с предметом | Закрыть приложение из списка задач |
| Повреждённое сохранение | Невалидные JSON/типы отклоняются, используется последняя валидная копия | Проверить сообщение и свободное место |
| Несколько слотов | Независимые состояния, запрет неверного номера | Проверить удобство выбора |
| Два пальца | Джойстик и прыжок удерживаются независимо | Проверить сенсорные задержки |
| Кнопка «Назад» | Обработчик открывает паузу; Escape на ПК | Системная кнопка и жест |
| Входящий звонок/аудиофокус | Реализовано сохранение/пауза при потере фокуса | Обязателен реальный звонок |
| Нехватка памяти | Ограничен размер JSON, проверяются ошибки записи | Низкая память, заполненное хранилище, убийство процесса ОС |
| Поворот экрана | Зафиксирована landscape-ориентация | Заблокировать/разблокировать поворот ОС |
| 16:9–21:9 и вырезы | 320×180 с целым масштабом и полями; безопасная область Android | Телефон с вырезом, жестовая навигация |
| Читаемость и касания | Основные кнопки 26–28+ логических px; изменение размеров/сдвига | Проверить минимум 48 dp на целевом DPI |
| Звук | 3 оригинальные петли, 5 эффектов Ogg, ограниченный пул голосов | Наушники, Bluetooth, громкости, аудиофокус |
| Производительность | См. desktop_performance.json; это программный OpenGL ПК | 60 FPS, холодный старт ≤5 с, память ≤600 МБ |
| Установка и холодный рестарт | CI дополнительно запускает x86_64-вариант того же кода на API 35 | Установить финальный ARM64 APK |

Эмуляторный сценарий устанавливает APK, читает начало истории касаниями,
доходит до реального хаба, принимает поручение джойстиком и кнопкой,
закрывает процесс и проверяет продолжение. Его состояние/кадры/логи сохраняются
как `android-smoke-evidence`; результат необходимо смотреть в соответствующем CI run.
Эмуляторный APK отдельный, пользователю выдаётся только ARM64-сборка.

Художественная доводка: полноценные циклы анимаций, контраст силуэтов,
возрастные спрайты эпилога и историческая архитектура — ART_BIBLE.md.
