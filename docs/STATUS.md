## Выдача и пределы готовности

Финальный CI экспортирует ARM64 APK, проверяет aapt/apksigner, размер ≤150 МиБ,
пакет/версию/SDK и отсутствие INTERNET; упаковывает APK, инструкцию и SHA-256
в ZIP. Дополнительно ставит x86_64-вариант того же кода в эмулятор API 35,
доходит касаниями до хаба, принимает поручение и проверяет холодное продолжение.
Результат финального CI и ссылка на выдачу будут записаны после завершения run.

ARM64 APK из run 39002087914 скачан через GitHub-коннектор и независимо разобран:
29,03 МиБ, пакет/версия/SDK/ABI верны, ZIP и SHA-256 совпали, подписи v2/v3
прошли. Первая smoke-попытка нашла старое имя Activity в самом тесте;
исправлено определением launcher через Package Manager. Повторный run проверит касания.

Run 39002493906 прошёл сборку и эмуляторный сценарий. Просмотр кадров выявил
перекрывающую системную подсказку полноэкранного режима; сценарий усилен:
подтверждает подсказку и требует реального движения героя после холодной загрузки.
Итоговая выдача ждёт этой дополнительной проверки.

Дальнейшая проверка logcat нашла ошибку старого GPU эмулятора swiftshader_indirect:
встроенные шейдеры Godot превышали его лимит fragment uniforms. После двух
пустых кадров этот путь обойдён драйвером swangle; smoke теперь проверяет
содержимое кадров и отсутствие ошибок линковки, а не только работу логики.

Физический Android, звонок, аудиофокус, вырезы, размеры в dp и мобильные бюджеты
пока требуют ручной проверки. Полные циклы анимации, возрастные спрайты,
историческая/художественная редактура и английский перевод остаются доводкой.
См. KNOWN_ISSUES.md и QA_CHECKLIST.md. Незавершённых сюжетных глав нет.
