# Сюжет: устройство и продолжение работы

Часть II находится в работе. Источник текста — восемь JSON в `story/chapters/`.
Главы 1–2 имеют `prose_status: complete`, остальные сцены — `draft`.
Это статусы литературного прохода, а не автоматическое доказательство качества.

## Центральная линия

Пулон пытается перестать принимать всякую чужую беду за повод первым броситься
вперёд. Ворен учится различать порядок и исполнение удобного приказа.
Их связь начинается с соперничества, проходит через взаимное спасение,
а затем проверяется выбором между службой и мирной жизнью. Общая история
мастерской Луциллы связывает военные годы с теми, кто остаётся дома.
Частные долговые записи приобретают значение как свидетельства людей,
а не как предмет, способный изменить исход гражданской войны.

## Существенные решения

| Узел | Решение | Уже работающий отдалённый результат |
| --- | --- | --- |
| `ch01_s03_n90` | Оборона или помощь людям Нерии | `neria_trust` открывает попытку предупредить обе группы в 43 году при bond ≥ 60 |
| `ch02_s08_n90` | Продлить службу / остаться гражданином | Девять военных либо восемь городских сцен главы 3 |
| `ch03_s05_n90` / `ch03_s13_n90` | Семья Аглаи или бумаги/деньги | `aglaia_safe` вместе с bond ≥ 65 открывает совместное спасение у Акция |
| `ch04_s07_n90` | Сохранить / сжечь частную копию | `ledger_survives` влияет на вместе/порознь и итог предательства |
| `ch05_s01_n90` | Четыре стороны | Репутации, флаги стороны и разные требования домашней концовки; развёрнутая партийная проза ещё нужна |
| `ch05_s04_n90` | Писец / семья / обе группы при условиях | Разные флаги эвакуации; судьбы близких участвуют в плохом исходе |
| `ch06_s05_n90` | Вывести людей / передать список | Пропуска, дом, предательство и уязвимость Луциллы |
| `ch07_s03_n90` | Вместе / жертва / приказ | Авл спасён лично героями, Ворен потерян либо отношения разрушены; три отдельных последствия |
| `ch08_s01_n90` | Общедоступные свидетельства / семейная копия | `home_claim`, `archive_public`, доступность совместного дома |

Десять узлов помечены крупными; две версии александрийского решения находятся
в разных линиях. В одном прохождении игрок видит девять таких узлов.
Остальные ответы меняют bond, репутацию, частные флаги и ближайшие последствия.
Флаги небольших сцен не все имеют завершённое литературное продолжение —
это входит в оставшуюся работу глав 3–8.

## Разрешение концовок

В `ch08_resolution` порядок имеет значение:

1. Предательство без сохранившегося свидетельства, либо крайне низкое доверие
   без помощи обеим близким группам — «Список без имён».
2. `friend_lost` — «Один светильник».
3. Высокое доверие, сохранённые записи, помощь Авлу и условия выбранной стороны
   — «Два места у очага». Для нейтральных/Октавиана нужен домашний статус,
   для Антония/республиканцев более высокий bond и безопасный проход.
4. Остальные сочетания — «Письма через море».

Плохая концовка имеет приоритет над утратой: это итог распада сети доверия,
а не только отдельной смерти. Все четыре исхода проверяются с начала игры
на обеих линиях. Точные условия хранятся в JSON, их не дублирует код экрана.
Баланс bond пока предварительный: последовательность всех положительных ответов
достигает 100. Нужен редакторский проход смешанных решений, не только крайних.

## Данные и раннер

- `characters.json`: имена, вымышленные линии, условные годы рождения.
- `flags.json`: определения булевых флагов, начальный bond, репутации.
- `portraits.json`: 40 эмоций и совместимый псевдоним `vorenus_stern`.
- `beats.json`: 12 слотов тактики, платформера и RPG с местом, целью и победой.
- `history_events.json`: 28 исторических меток, обязательных на обеих линиях.
- `ui_ru.json`: надписи интерфейса; повествование находится только в главах.
- `test_routes.json`: автоматически полученные пути для независимой проверки Godot.

Один узел — текст с говорящим/портретом, выбор, переход, слот или окончание.
Условия: флаг, `!флаг`, сравнение `bond>=65`, `rep.citizens>=2`, соединение
`&` и альтернатива `|`. Скобок и исполнения выражений как кода нет.
Альтернативы перечисляются явно. Каждый выбор имеет безусловный выход.
Эффекты: set_flags, clear_flags, bond, rep. Диапазоны bond 0…100,
репутации −100…100. Побочный эпизод имеет явное приглашение и отказ.

Порядок боевого слота: проза → решение → слот → выбранное последствие.
Слот работает кнопкой выполнения, без реального боя/платформера. Она не меняет
исторического результата и предназначена для замены механиками части III.
Взаимное спасение 54 года остаётся общим для обоих ответов.

Автосохранение `user://cinis_story_v2.json` содержит флаги, bond, репутации,
текущий узел, прогресс, журнал, сделанные выборы и завершённые слоты.
Запись идёт через временный файл и переименование. Эффекты текста применяются
один раз. Некорректный JSON и неподходящая версия отклоняются.
Тесты используют отдельные файлы и не заменяют сохранение игрока.

Выбор главы — инструмент проверки: раннер проходит предыдущие главы первыми
доступными ответами, с указанной линией главы 3. Это создаёт реальное достижимое
состояние, но заменяет текущий прогресс. Для обычного продолжения есть «Продолжить».
Пропуск сцены также выбирает первые доступные ответы и завершает слоты.

## Как дописывать

1. Читать существующие узлы выбора и последствия сцены до замены вводной прозы.
   Сначала следующие — обе линии главы 3; затем общая глава 4.
2. Заменять только текстовые узлы `_n01`…`_n69`. Узлы `_n70` и выше
   сохраняют управление, решения и последствия. Помощник `tools/story_editor.py`
   принимает JSON через stdin и сохраняет выход из заменяемой последовательности.
3. Добавлять условные реплики через поле `condition`, обязательно оставляя
   общий выход. Особенно после `friend_lost` исключать реплики живого Ворена.
4. Стремиться к 25–35 тысячам **уникального** текста во всех ветках и 120–180
   минутам на обычном пути при 200 слов/мин. Заголовки, метаданные и невыбранные
   ответы не увеличивают время конкретного прохождения.
5. После блока запускать `python tools/validate_story.py --draft`, затем Godot
   `tools/verify_story.gd`. Финальная приёмка — валидатор без `--draft`.

Начальные генераторы каркаса не входят в репозиторий и не должны повторно
перезаписывать главы. Английские поля оставлены пустыми в соответствии с PDF.
